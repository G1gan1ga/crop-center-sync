# AgriFlow Connect

Build a working responsive web app for smart procurement-centre management based on the attached problem: farmers can register, book a procurement slot, see live queue position and expected wait; centre staff/admin can manage queues and update procurement and payment statuses. Include polished role-aware demo flows, accessible Indian government/agriculture-inspired design, seeded sample data, clear dashboard, booking form, notifications/status timeline, and an admin operations view. Enable Lovable Cloud if needed for persistent data/auth; otherwise ensure the complete demo works end-to-end.
